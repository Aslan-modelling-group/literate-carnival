# M02 installation

Upload the contents of this package into the repository root.

It adds only:

```text
src/core/
docs/architecture/M02_CORE_FOUNDATION.md
docs/architecture/M02_INSTALL.md
```

Do not delete or replace existing files.

After upload, verify the repository before the next M02 unit. On a machine with the repository available, run:

```bash
npx tsc --noEmit
npm run build
```

If either command fails, stop there and repair M02 before continuing.
